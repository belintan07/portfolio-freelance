## 📦 How to Upload to Google Drive (The "One Link You Can Send")

1. **Convert the 3 Case Study Readmes into PDFs:**
   * Open each `README.md` (or HTML preview) in your browser or Markdown viewer.
   * Press `Ctrl + P` (Print) → `Save as PDF`.
   * Name them cleanly:
     - `01_Sample_SaaS_Landing_Conversion_Engine.pdf`
     - `02_Sample_NodeJS_Idempotent_Payment_API.pdf`
     - `03_Sample_Python_AI_Agent_MCP_Server.pdf`

2. **Add Screen Recordings or Live Links:**
   * Record a short 30–60 second Loom / clip showing each interactive prototype running.
   * Add each clip to its respective subfolder in Google Drive.

3. **Google Drive Folder Structure:**
   ```text
   📁 Belintan — Full-Stack & AI Engineering Samples (Public)
   │
   ├── 📄 00_Overview_ReadMe.pdf
   ├── 📁 01_SaaS_Frontend_CRO_Sample/
   │   ├── Case_Study_PulseScale.pdf
   │   └── Interactive_Demo_Preview.html
   ├── 📁 02_NodeJS_Idempotent_API_Sample/
   │   ├── Case_Study_VaultFlow.pdf
   │   └── API_Testbench_Walkthrough.mp4
   └── 📁 03_Python_AI_MCP_Agent_Sample/
       ├── Case_Study_CortexMCP.pdf
       └── MCP_Agent_Interactive_Dashboard.html
   ```

4. **Public Link Setting:**
   * Right-click the parent folder in Google Drive → `Share` → Under *General access*, select **"Anyone with the link can view"**.

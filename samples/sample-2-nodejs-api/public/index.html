🛡️ Technical Architecture Notes

In high-scale systems, networks fail and gateways retry. Without strict idempotency keys and cryptographically verified signatures, customers get billed multiple times. This Node.js engine uses in-memory / Redis atomic set-if-not-exists (`SETNX`) logic to guarantee exactly-once processing semantics.
